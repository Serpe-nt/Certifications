## m09-s01 Why a Collector: the agent and gateway patterns

| Statement or action | Source or evidence | Date | Status |
|---|---|---|---|
| The Collector receives, processes and exports telemetry to one or more targets | arch (first paragraph); col-index | 2026-11-13 | checked |
| Sending straight to a backend is fine to start, in development or small scale | col-index ("When to use a collector") | 2026-11-13 | checked |
| A Collector lets the service offload data quickly; it handles retries, batching, encryption, sensitive data filtering | col-index | 2026-11-13 | checked |
| The SDKs' default OTLP exporters assume a local Collector endpoint | col-index | 2026-11-13 | checked |
| No Collector: code changes when collection, processing or ingestion changes; coupling to the backend; limited exporters per language | no-col (Trade-offs) | 2026-11-13 | checked |
| Agent: alongside the application or on the same host, such as a sidecar or DaemonSet; each SDK gets the Collector's address | agent | 2026-11-13 | checked |
| Agent pros: easy start, one-to-one mapping; cons: limited scalability, inflexible for complex deployments | agent (Trade-offs) | 2026-11-13 | checked |
| Gateway: one OTLP endpoint served by one or more Collectors as a standalone service, e.g. a Kubernetes Deployment; per cluster, data center or region; a load balancer in front | gateway | 2026-11-13 | checked |
| Gateway pros: centrally managed credentials, central policy (filtering, sampling); cons: one more thing that can fail, added latency when cascaded, higher resource usage | gateway (Trade-offs) | 2026-11-13 | checked |
| Agent-to-gateway: agent configurations stay small; gateways do sampling, filtering, transformation; gateways are a stable egress point handling retries and credentials | a2g | 2026-11-13 | checked |
| When simpler patterns are enough (direct OTLP, no host metrics or logs, no complex processing, small deployment) | a2g ("When simpler patterns work better") | 2026-11-13 | checked |
| Lab: Deployment `otel-gateway` in `otel`, 2 replicas, no agent Collectors | `kubectl -n otel get deploy,pods` (2/2 Ready, image contrib 0.165.0) | 2026-11-13 | run on the lab |
