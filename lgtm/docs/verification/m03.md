## m03-s03 Metric types: counter, gauge, histogram, summary

Extra source: functions = https://prometheus.io/docs/prometheus/latest/querying/functions/ ; nh = https://prometheus.io/docs/specs/native_histograms/

| Statement or action | Source or evidence | Date | Status |
|---|---|---|---|
| Client libraries offer four core types | types | 2026-11-12 | checked |
| Counter: only increases or resets to zero on restart; examples requests, tasks, errors; never for a value that can decrease | types (counter), pyc-counter | 2026-11-12 | checked |
| `rate()` adjusts for breaks in monotonicity such as counter resets | functions (rate) | 2026-11-12 | checked |
| A queue length exposed as a counter that falls is read as a reset by `rate()`, giving a false rate | inference from functions (rate) and types (counter) | 2026-11-12 | inference |
| Gauge: can go up and down; examples memory usage, temperature, concurrent requests | types (gauge) | 2026-11-12 | checked |
| Rule of thumb: if the value can go down, it is a gauge | instr ("Counter vs. gauge") | 2026-11-12 | checked |
| Histogram: counts observations in buckets and provides a sum; "essentially a bucketed counter" | types (histogram) | 2026-11-12 | checked |
| Classic histogram series `_bucket{le}` (cumulative), `_sum`, `_count` equal to `le="+Inf"` | types (histogram), expo (histograms and summaries) | 2026-11-12 | checked |
| `histogram_quantile()` calculates quantiles from histograms or aggregations of histograms | types (histogram) | 2026-11-12 | checked |
| Figures part: buckets 0.1 = 33444, 0.5 = 129389, 1 = 133988, +Inf = 144320 = `_count` | expo (example exposition) | 2026-11-12 | checked |
| Native histogram: composite samples with count, sum and a dynamic set of buckets; no bucket boundaries configured during instrumentation; more efficient, higher resolution | types (histogram) | 2026-11-12 | checked |
| Native histograms stable since v3.8.0; scraping must be activated with `scrape_native_histograms`; earlier behind the `native-histograms` feature flag since v2.40.0 | nh (intro), migration | 2026-11-12 | checked |
| Summary: sum, count, streaming φ-quantiles over a sliding window as `<basename>{quantile="φ"}` | types (summary) | 2026-11-12 | checked |
| Summary observations relatively expensive; quantile query fast; quantiles and window preconfigured; not aggregatable. Classic histogram aggregatable when bucket boundaries do not change | histo (comparison table) | 2026-11-12 | checked |
