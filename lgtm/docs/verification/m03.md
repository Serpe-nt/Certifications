## m03-s02 The data model: name, labels, samples

| Statement or action | Source or evidence | Date | Status |
|---|---|---|---|
| Prometheus stores all data as time series; a series is identified by metric name and labels; "dimensional data model" | datamodel | 2026-11-12 | checked |
| Changing any label value, or adding or removing a label, creates a new series | datamodel | 2026-11-12 | checked |
| Notation `name{label="value", ...}`; example `api_http_requests_total{method="POST", handler="/messages"}` | datamodel (notation) | 2026-11-12 | checked |
| The metric name is internally the label `__name__`; `{__name__="..."}` form | datamodel (notation) | 2026-11-12 | checked |
| A sample is a float64 or native histogram value and a millisecond-precision timestamp | datamodel (samples) | 2026-11-12 | checked |
| The server flattens all types except native histograms into untyped float series | types (intro) | 2026-11-12 | checked |
| UTF-8 metric and label names since v3.0.0; recommended character sets; names outside them need quoting in PromQL | datamodel, migration ("UTF-8 names") | 2026-11-12 | checked |
| Prometheus 2 flagged such names as invalid | migration ("names that would have previously been flagged as invalid no longer will be") | 2026-11-12 | checked |
| Label names starting with `__` are reserved for internal use | datamodel | 2026-11-12 | checked |
| Colons are reserved for user-defined recording rules; exporters and direct instrumentation should not use them | datamodel (note) | 2026-11-12 | checked |
| A label with an empty value is equivalent to a label that does not exist | datamodel | 2026-11-12 | checked |
