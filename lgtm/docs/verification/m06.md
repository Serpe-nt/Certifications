| Statement or action | Source or evidence | Date | Status |
|---|---|---|---|

| The kubelet also serves `/metrics/cadvisor`, `/metrics/resource` and `/metrics/probes` | sysmetrics | 2026-11-12 | checked |
| cAdvisor is built into the kubelet and collects container metrics | pipeline ("cAdvisor: Daemon for collecting, aggregating and exposing container metrics included in Kubelet") | 2026-11-12 | checked |
| Node exporter: machine metrics for Linux and Unix (CPU, memory, disks, file systems, network) | ne | 2026-11-12 | checked |
| kube-state-metrics listens to the API server and makes metrics from object state (deployments, nodes, pods); not about component health | ksm (Overview); k8s-ksm | 2026-11-12 | checked |
| etcd and the control plane components serve `/metrics` | sysmetrics; https://etcd.io/docs/v3.6/op-guide/monitoring/ (etcd `/metrics`) | 2026-11-12 | checked |
| Containers log to stdout and stderr; logs kept on the node in `/var/log/pods`; kubelet rotates them (10Mi, 5 files by default); `kubectl logs` reads only the latest file | logging ("Log rotation", "Log locations") | 2026-11-12 | checked |
| Kubernetes has no native storage for logs; cluster-level logging; node-level agent as a DaemonSet | logging | 2026-11-12 | checked |
| Events kept one hour by default (`--event-ttl` default `1h0m0s`) | apiserver-ref | 2026-11-12 | checked |
