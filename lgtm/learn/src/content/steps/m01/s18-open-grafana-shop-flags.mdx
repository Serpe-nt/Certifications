## The names and how they resolve

The lab's screens include `grafana`, `shop`, `flags`, `loadgen`, `prometheus`, `alertmanager` and `longhorn`, each followed by `.lab.k8s.local`. On Windows they resolve through the rule that `lab-vms.ps1 create -ConfigureDns` added. WSL does not use that rule, so from WSL you reach the same screen as `http://10.10.0.5` with a `Host:` header, for example `curl -H 'Host: grafana.lab.k8s.local' http://10.10.0.5/api/health`. `lgtm/lab/docs/reference.md` lists every address.

## Grafana

Grafana's user is `admin`. The password was made by the first `make lab` and is kept in the Secret `grafana/grafana-admin`; `make reset` does not change it. Grafana already has the data sources `mimir`, `loki` and `tempo` with data from the shop, and the folder Shop holds one dashboard per service. Explore, in the left menu, lets you query any data source directly; step 19 uses it.

## The shop and the flag screen

The shop is the astronomy shop of the OpenTelemetry Demo, trimmed for this lab. A load generator places orders all the time, so the stores always have fresh data. The flag screen, Flagd Configurator, lists the shop's fault flags, each with its options; all of them are off after an install. Later modules switch a flag on, watch the fault in Grafana, and switch it off again.

<Question id="q-m01-s18" answer="b">
In WSL, `curl http://grafana.lab.k8s.local` fails with `Could not resolve host`, while the same address works in a Windows browser. Why?

- Grafana only accepts requests from Windows

  Grafana answers any client that reaches it; this is a name lookup failure.

- WSL does not use the Windows rule that sends .k8s.local names to the lab DNS

  The rule is set on Windows only, so WSL needs 10.10.0.5 and a Host header, or its own hosts entry.

- The gateway blocks curl and allows only browsers

  The gateway routes by host name, not by client type.

- Grafana is down, and the browser shows a cached page

  The error is about resolving the name, before any request reaches Grafana.
</Question>
